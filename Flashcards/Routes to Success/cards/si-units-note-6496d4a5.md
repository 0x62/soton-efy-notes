## What role do SI units and assumptions about ranges play when checking answers?

---

SI units provide a consistent system for checking dimensional consistency; plausible ranges help flag unrealistic results.

- Use SI base units (m, kg, s, A, K, mol, cd) for dimensional checks.
- If a result lies far outside expected SI ranges (e.g., a human speed of 10^6 m/s), re-check calculations and assumptions.
