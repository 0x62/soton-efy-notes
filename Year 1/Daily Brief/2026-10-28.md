### Useful concepts: structures, pointers and memory ownership

- An **array** groups values of the same type. A **structure** groups related fields, which can have different types—for example, the real and imaginary parts of a complex number.
- `value.real` accesses a structure directly. `pointer->real` accesses a structure through its address; it means the same as `(*pointer).real`.
- `malloc` reserves a requested number of bytes and returns their address. Check that allocation succeeded before using the memory. `free` releases the allocation when it is no longer needed.
- For an array of `n` objects, request `n * sizeof *pointer` bytes rather than assuming a particular machine's type size. Structure padding can also make a structure larger than the sum of its visible fields.

### Small worked example

```c
typedef struct {
    double real;
    double imag;
} Complex;

Complex z = {3.0, 4.0};
Complex *p = &z;
p->real += 2.0;
```

1. `z` initially represents **3 + 4j**.
2. `p` stores the address of `z`; it is not a second complex-number object.
3. `p->real += 2.0` changes `z.real` from 3 to 5. The result is **5 + 4j**; `z.imag` remains 4.
4. No heap allocation occurred here, so there is nothing to pass to `free`.

**Takeaway:** distinguish an object from a pointer to it, and distinguish automatic storage from allocated storage. **Useful prep:** identify which function owns each allocation in any code you want to discuss; that makes a leak or invalid access much easier to locate.

### The distinctions that matter

- **Instantaneous power:** $p(t)=v(t)i(t)$, the power at a particular instant.
- **Average real power:** for sine waves, $P=V_{\rm rms}I_{\rm rms}\cos(\theta_v-\theta_i)$, measured in watts. The phase difference matters: multiplying two RMS magnitudes alone is not generally the real power.
- **Complex power:** write $S=P+jQ$. Its real part is average power; its imaginary part is reactive power, measured in var, associated with energy moving into and out of ideal inductors and capacitors.
- **Peak versus RMS:** the slides use peak-valued phasors in $S=\tfrac12VI^*$. With RMS-valued phasors the equivalent formula is $S=V_{\rm rms}I_{\rm rms}^*$. The star means conjugate the **current**, reversing its phase angle. Do not use the half twice.
- **Decibels:** power ratios use $10\log_{10}(P_o/P_i)$. Voltage-amplitude ratios use $20\log_{10}|V_o/V_i|$; interpreting this as a power ratio requires equal resistances. Half voltage is about **−6.02 dB**, whereas half power is about **−3.01 dB**.

### Worked example: why phase changes the answer

**Illustrative numbers, not measurements:** let the RMS voltage be $10\angle0^\circ$ V and RMS current $2\angle-60^\circ$ A.

1. Conjugate the current: $I^*=2\angle+60^\circ$ A.
2. Multiply magnitudes and add angles: $S=10\times2\angle60^\circ=20\angle60^\circ$ VA.
3. Real part: $P=20\cos60^\circ=20\times0.5=\mathbf{10\ W}$.
4. Imaginary part: $Q=20\sin60^\circ=20\times0.866=\mathbf{17.3\ var}$.
5. The apparent power is $|S|=20$ VA, but the average real power is only 10 W. The positive reactive part corresponds to this lagging-current, inductive case.

### Worked slide example: matching a resistive load

The deck compares a **10 V peak** source with an **8 Ω** series resistance and several loads. For an 8 Ω load:

1. Voltage division gives $V_{L,\rm peak}=10\times8/(8+8)=5$ V.
2. Convert to RMS: $V_{L,\rm rms}=5/\sqrt2=3.536$ V.
3. Average load power is $P_L=V_{L,\rm rms}^2/R_L=12.5/8=\mathbf{1.5625\ W}$.

For a source impedance $R_s+jX_s$, the general matching condition in the deck is $R_L=R_s$ and $X_L=-X_s$: the load cancels the source reactance. This is **week-wide preparation**, not a promise that today's lecture reaches it.

**Takeaway:** state whether a voltage/current is peak or RMS before calculating power, and keep real power separate from apparent power. **Useful prep:** on PS5, keep impedance arithmetic and phase angles consistent; its hand-in closes at the start of tomorrow's tutorial.

4. Differentiate $x^x$ using **logarithmic differentiation**; both its base and exponent vary.

### Worked worksheet method: $f(x)=1/x$

1. Form the difference quotient:
   $$\frac{f(x+h)-f(x)}h=\frac{1/(x+h)-1/x}{h}.$$
2. Put the numerator over one denominator:
   $$\frac{x-(x+h)}{h\,x(x+h)}=\frac{-h}{h\,x(x+h)}.$$
3. Cancel $h$ while it is nonzero: $-1/[x(x+h)]$.
4. Now let $h\to0$: **$f'(x)=-1/x^2$**, for $x\ne0$.

The cancellation comes **before** taking the limit; substituting $h=0$ into the original quotient would give an unhelpful $0/0$.

### Worked worksheet method: $y=x^x$, $x>0$

1. Take natural logs: $\ln y=x\ln x$.
2. Differentiate both sides: $y'/y=\ln x+x(1/x)=\ln x+1$.
3. Multiply by $y$ and substitute back: **$y'=x^x(\ln x+1)$**.

**Takeaway:** choose the representation that makes the operation simple—polar form for complex products, a common denominator for a derivative limit, and logarithms when the variable appears in both base and exponent. **Useful prep:** distinguish “find the derivative” from “derive it by the specified method”; the worksheet explicitly asks for the latter in Question 3.
