## 09:00 · Circuits: power in balanced three-phase systems

**Yoshi Tsuchiya.** YT11 builds on star-connected loads. For a sinusoid the RMS amplitude is the peak divided by $\sqrt{2}$. In a balanced system, compute complex power for one load phase using RMS phasors, $S_\mathrm{phase}=V_\mathrm{phase}I_\mathrm{phase}^{*}$, and multiply by three. The conjugate makes the angle the **voltage phase minus the current phase**. The real part is power in watts; the imaginary part is reactive power in var. With peak phasors instead of RMS phasors, the product has an extra factor of $1/2$.

**Example:** a balanced star load draws 10 A line current from a 400 V line-to-line RMS supply at a 0.8 lagging power factor. The voltage across each branch is $400/\sqrt{3}$ V. Real power is $3(400/\sqrt{3})(10)(0.8)\approx 5.54\,\mathrm{kW}$. Reactive power is positive: the current lags, and $Q=3(400/\sqrt{3})(10)(0.6)\approx 4.16\,\mathrm{kvar}$.

**Takeaway:** decide whether the voltage is across a load phase or between two lines before calculating power. [Dated Circuits schedule](https://moodle.ecs.soton.ac.uk/mod/page/view.php?id=43581) · [YT11 slides](https://moodle.ecs.soton.ac.uk/mod/resource/view.php?id=46378).

## 10:00 · Programming

**Steve Gunn's current slides: Analogue Input.** No separate topic is posted for this Friday slot. The slides separate **sampling**, choosing when to measure, from **quantisation**, choosing the digital level that represents each measurement. The Il Matto's port A pins provide ADC input channels; the analogue comparator, by contrast, reports which of two voltages is higher.

**Example:** with a 10-bit ADC and a 3.3 V reference, one code step is approximately $3.3/1024=3.22\,\mathrm{mV}$. Taking one sample every 20 ms gives 50 samples/s. Changing the reference changes volts per count, not the sampling rate. If the readings look wrong, check pin, reference and raw code before debugging volts or beats per minute.

**Takeaway:** know which quantity the hardware produces and which quantity your program calculates from it. [Analogue Input slides](https://moodle.ecs.soton.ac.uk/mod/resource/view.php?id=36220) · [C9 lab reference](https://moodle.ecs.soton.ac.uk/mod/page/view.php?id=36054).

## 12:00 · Digital Systems (L2)

**Preparation from Mark Zwolinski's current materials; specific topic not assigned to this slot on Moodle.** For a simple processor, trace one instruction from the program counter through instruction memory, the decoder and the ALU. Write down which part of the instruction specifies an operation and which part is a number or address. For example, an immediate add uses the number in the instruction, whereas a load uses that field as an address to read data.

**Takeaway:** distinguish the address of the instruction being executed from the data address it uses. Bring one instruction trace that you can explain clock edge by clock edge. ## 15:00 · Digital Systems (L4)

**Preparation from Mark Zwolinski's current materials; specific topic not assigned to this slot on Moodle.** Review what happens when two outputs share a bus. A disabled tri-state driver is high impedance ($Z$), not a logic zero. If both drivers are enabled and one drives high while the other drives low, the bus is in contention. If neither drives, the bus does not acquire a valid value just because both outputs are disabled.

**Takeaway:** draw an enable column next to the data column. In a shared-bus design, check which device, if any, is allowed to drive in each state. [Tri-state Logic and Buses slides](https://moodle.ecs.soton.ac.uk/mod/resource/view.php?id=36390) · [Digital Systems module](https://moodle.ecs.soton.ac.uk/course/view.php?id=901).

## 16:00 · Mathematics: Linear Algebra

**Paolo Rapisarda.** The first teaching block covers vectors, subspaces, linear combinations and span, independence, bases and dimension, and an introduction to linear transformations. The lecture notes cover this in §§1.1–1.4. A **basis** is an independent set that spans the space. The coordinates of a vector say how much of each basis vector to use; they can change when the basis changes, even though the vector stays the same.

**Example:** to express $(6,2)$ in the basis $(1,1),(1,-1)$, write $a(1,1)+b(1,-1)=(6,2)$. The component equations are $a+b=6$ and $a-b=2$. They give $a=4$, $b=2$: the new coordinates are $(4,2)$.

**Takeaway:** check spanning and independence separately. Try self-study questions 1–5 on p. 46 before the lecture. [Lecturer announcement](https://moodle.ecs.soton.ac.uk/mod/forum/discuss.php?d=2824) · [Linear Algebra notes](https://moodle.ecs.soton.ac.uk/mod/resource/view.php?id=45729).
