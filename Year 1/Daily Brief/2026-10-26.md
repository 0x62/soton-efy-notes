## 15:00–16:00 · Circuits

**Lecturer: Prof Neil White. Scheduled session: NMW07. Week-wide material: AC Power.** The dated module schedule identifies today’s session, but the precise stopping point within the Week 6 deck is not confirmed.

### Concepts

- **Instantaneous and average power differ.** Multiplying voltage and current gives power at each instant. Its average over a complete cycle determines net energy transferred per second. A large instantaneous peak does not imply the same average power.
- **Phase affects useful power.** For sinusoidal voltage and current with RMS magnitudes, real power is $P=V_{\mathrm{rms}}I_{\mathrm{rms}}\cos\phi$, where $\phi$ is voltage phase minus current phase. An in-phase load has unity power factor; a phase difference reduces real power for the same RMS voltage and current.
- **Complex power keeps both parts.** $S=P+jQ=V_{\mathrm{rms}}I_{\mathrm{rms}}^*$, with real power $P$ in watts and reactive power $Q$ in var. Its magnitude is apparent power in VA. The conjugate is essential: it produces the voltage–current phase difference, not the sum.
- **Amplitude convention matters.** The slides use peak-amplitude phasors in $S=\tfrac12 VI^*$. RMS phasors remove that factor of one half. For a sinusoid, each RMS magnitude is its peak divided by $\sqrt2$.

### Worked example

For the slides’ **in-phase 8 V peak voltage and 4 A peak current**, take

$$v(t)=8\cos\omega t,\qquad i(t)=4\cos\omega t.$$

Then

$$p(t)=32\cos^2\omega t=16+16\cos2\omega t\ \mathrm{W}.$$

The instantaneous peak is **32 W**, while average power is **16 W**. Equivalently, $(8/\sqrt2)(4/\sqrt2)=16\ \mathrm{W}$.

**Supplementary extension:** if the current instead lags by $30^\circ$, the same magnitudes give $S=16\angle30^\circ\ \mathrm{VA}$, so $P\approx13.86\ \mathrm{W}$ and $Q=8\ \mathrm{var}$. This extension illustrates the formula; it is not a claim about a specific slide or today’s exercise.

**Takeaway:** state peak or RMS before calculating, and distinguish watts, var and VA. **Useful prep:** phasor conjugation and rectangular/polar conversion are the immediate prerequisites. Today’s schedule also lists **Problem Sheet 6 being set**; actual release is not yet confirmed.

### Concepts and worked example

A structure groups related named values; an array groups repeated values of a type. A pointer to a structure uses `p->member`, equivalent to `(*p).member`. Allocating memory creates storage, not automatically meaningful initial values: successful `malloc` storage must be initialised before its values are read, and every owned allocation needs a matching release after its final use.

For a flat, row-major **3 × 4 matrix**, the element at zero-based row 1, column 2 has index

$$1\times4+2=6.$$

Twelve `double` values require `12 * sizeof(double)` bytes. A pointer to this contiguous block is not interchangeable with `double **`: the latter points to pointers, normally requiring a separate row-pointer array and an explicit allocation/cleanup strategy. Casting a flat buffer does not manufacture row pointers.

**Takeaway:** choose the representation and ownership model together. **Useful prep:** follow one allocated object from creation through use to `free`, and distinguish the lifetime of a local pointer variable from the lifetime of its allocated storage.

### Supplementary technical consolidation

A hardware description describes concurrently operating circuitry, not a processor executing every statement in sequence. For combinational procedural logic, every output must receive an assignment for every input path; otherwise retaining an earlier value can imply storage. A `logic` declaration alone does not mean a physical register.

For a one-bit full adder,

$$S=A\oplus B\oplus C_{in},\qquad C_{out}=AB+AC_{in}+BC_{in}.$$

With $A=1$, $B=0$, $C_{in}=1$, the sum output is 0 and carry is 1. The arithmetic check is

$$2C_{out}+S=2=A+B+C_{in}.$$

This is a compact way to test all eight input combinations independently of whether the circuit is described structurally or with Boolean expressions.

**Takeaway:** distinguish a description’s syntax from the hardware and truth table it implies. **Useful prep:** check bit widths, complete combinational assignments and the expected output for each input combination.
